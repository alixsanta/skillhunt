# Frontend Web Setup (SH-19) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffold a standalone `frontend-web/` React project (routing, design system, typed API client, test harness, CI) so the SkillHunt frontend can be built in parallel with the backend, with no business screens yet.

**Architecture:** Vite + React 18 + TypeScript (strict) as a standalone service sibling to `backend-core/` and `matching-service/` (no root workspace). Feature-oriented folder layout mirroring the backend. Design system via Tailwind CSS + shadcn/ui + Lucide. Data layer via TanStack Query + a single Axios instance, with API types generated from the backend's OpenAPI schema (`openapi-typescript`) and committed. Tests via Vitest + React Testing Library. A dedicated GitHub Actions workflow mirrors the existing `node-ci.yml`.

**Tech Stack:** Vite, React 18, TypeScript, React Router, Tailwind CSS (v4 via shadcn CLI), shadcn/ui, Lucide, TanStack Query, Axios, openapi-typescript, Vitest, React Testing Library, ESLint (flat config), Prettier.
